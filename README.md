# astrotarget
Planificateur d'observation astronomique

## Applications

- `astrotarget.py` — planificateur d'observation (Streamlit)
- `fits_photometry.py` — photométrie FITS
- `cielscore_satellites/` — **CielScore Satellites** : position des satellites de Jupiter, Saturne et Uranus — application Python/Streamlit et site statique JavaScript (`cielscore_satellites/web/`)
- `f1_prediction/` — prévision F1
